# Brand: Nowiutko

Decided 9 Nov 2026 by the owner, with the brand strategist (claude.ai). The same file lives in all four repos (cleaning-sell-system, cleaning-design, cleaning-seo, cleaning-sales); change it in all four together.

## Name

**Nowiutko** — from *nowiutki* ("brand new"): the customer's own promise, "jak nowe" (like new). Pronounced *no-VYOOT-ko*. Always written **Nowiutko** (capital N, no diacritics, one word). Never "NowiUtko", "Nowiutko.pl" as a name, or with a city in it.

## Brand elements

| Element | Decision |
|---|---|
| **Symbol** | A **chamomile flower (rumianek)** — gentle, safe for kids and pets, calm. White petals around a sunny-yellow centre, which matches the palette (mint / white / sun yellow). Rumianek is the symbol, not a name or sub-brand. |
| **Voice** | **Freshness** — *świeżo, jak nowe, bez wychodzenia z domu*. Warm, competent neighbour; "Ty" form; short sentences. |
| **Tagline (descriptive)** | *Nowiutko — pranie tapicerki, wózków i aut u Ciebie.* |
| **Line (voice)** | *Świeżo i jak nowe — bez wychodzenia z domu.* |
| **Master promise** | *Przyjeżdżamy na czas. Płacisz tyle, ile podaliśmy ze zdjęć. Jeśli coś wyjdzie po wyschnięciu, wracamy za darmo.* |

## One look across all services

One brand system everywhere: the same logo, fonts, buttons, layout and voice on every page. Each service gets only a **light accent inside the system**:
- an accent colour **from the same palette** (e.g. softer yellow for strollers, deeper teal for car)
- its own **icon** in one consistent icon style (stroller, sofa, paw, mattress, car)
- photos of its own subject, in the same photo style
- copy that speaks to its customer (Kasia, Tomek, Ola, Marek)

No sub-brands ("Nowiutko Baby", "Nowiutko Auto"), no different fonts or logos per service, no separate colour schemes.
